Function char_to_index

fn char_to_index(c: char) -> usize
Expand description

Convert a variable character to an array index ‘A’ -> 0, ‘B’ -> 1, …, ‘Z’ -> 25, ‘*’ -> 26

§Panics

This function panics if c is not in ‘A’..=‘Z’ or ‘*’. Invalid characters indicate a bug in the parser/solver logic.

The parser validates all variable characters before creating bindings, so invalid input here represents a programming error, not invalid user input.
