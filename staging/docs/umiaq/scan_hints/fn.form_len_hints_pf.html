Expand description

Compute per-form hints from a ParsedForm and the equation’s constraints. These are just length bounds for a parsed form

  • vcs: the full equation’s VarConstraints (we’ll only read vars present in form)
  • jcs: the equation’s JointConstraints (we’ll filter to constraints whose variable set is a subset of the form’s variables)
