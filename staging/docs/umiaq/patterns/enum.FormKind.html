Expand description

Classification of a single input “form” string into one of the supported categories.

Each variant corresponds to a different type of constraint or pattern that the solver recognizes, which is produced and consumed by EquationContext::set_var_constraints.

Variants§

NeqConstraint

An inequality constraint among a set of variables, e.g., !=ABC. Stores the set of variable characters that must differ.

Source§

fn from_str(s: &str) -> Result<Self, Self::Err>

Attempt to classify a raw input string into a specific kind of constraint or pattern.

This function is the central parser for forms. It tries each constraint type in turn, and if none match, falls back to treating the input as a ParsedForm pattern.

The result is wrapped in a FormKind enum, which can then be dispatched on by EquationContext::set_var_constraints.

§Order of checks
  1. Length comparison constraints (converted into ComplexConstraint), e.g., |A|=5.
  2. Inequality constraints, e.g., !=ABC.
  3. Complex constraints (get_complex_constraint).
  4. Joint constraints, e.g., |AB|=7.
  5. Plain parsed forms (patterns).

If none of these succeed, returns a ParseError::InvalidInput.

§Errors
  • Returns ParseError if the form is invalid or cannot be parsed as any recognized type.
